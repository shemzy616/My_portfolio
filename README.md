# Shem I. Muiruri — Portfolio

> *I hunt threats across logs — then automate the parts a human shouldn't repeat.*

A cybersecurity-focused portfolio built with React, TypeScript, and Tailwind CSS. Showcasing SOC engineering, threat detection automation, and full-stack development work.

## 🌐 Live Site

**[https://shemzy616.github.io/My_portfolio/](https://shemzy616.github.io/My_portfolio/)**

---

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Framework | React 18 + TypeScript |
| Styling | Tailwind CSS |
| Build Tool | Vite |
| Routing | React Router v7 |
| Deployment | GitHub Actions → GitHub Pages |

---

## 📂 Sections

- **About** — Bio and quick-info card
- **Capabilities** — Core service areas
- **Skills** — Interactive 3D skill globe (drag to spin)
- **Projects** — Flip-card project showcase (horizontal scroll)
- **Certifications** — Logo-strip of verified credentials
- **Experience & Education** — Timeline with keyword tags
- **Contact** — Terminal widget + direct channels

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
# → http://localhost:3000
```

---

## 📦 Deployment

Pushes to `main` automatically trigger a GitHub Actions build and deploy to GitHub Pages.

```bash
git add -A
git commit -m "your update"
git push origin main
```
